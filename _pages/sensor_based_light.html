This project is a personal home-automation build that I designed and assembled on my own using a Raspberry Pi and a PIR motion sensor. The system detects movement in a room and automatically turns the light on when someone enters, then switches it off again after inactivity.

I built it to explore practical automation with low-cost hardware and simple control logic. The main goal was to create something useful for a real room setup while learning sensor integration, GPIO control, and event-driven programming on Raspberry Pi.

What It Does

  • Monitors motion in the room using a PIR sensor,to detect if someone entered or left the room.
  • Turns the light on automatically when motion is detected / person enters the room.
  • Turns the light off when the person leaves the room.
  • Reduces the need for manual switching in day-to-day use.

Hardware Used

  • Raspberry Pi
  • PIR motion sensor
  • Light control interface / relay setup
  • Power supply and wiring components

How I Built It

The PIR sensor is connected to the Raspberry Pi GPIO pins and continuously reports motion activity. A Python-based control script reads the sensor state and triggers the output connected to the room light control circuit. Once motion is detected, the light is turned on immediately. If motion stops for a fixed interval, the light is switched off to save power.

While building the system, I focused on keeping the behavior stable enough for everyday use, avoiding unnecessary switching, and making the setup simple to expand later with features like adjustable timeout, manual override, or remote monitoring.

Key Takeaways

  • Hands-on experience with Raspberry Pi GPIO programming.
  • Practical understanding of motion sensing and automation logic.
  • Integration of hardware and software for a real-world use case.
  • Improved reliability considerations for small embedded projects.
