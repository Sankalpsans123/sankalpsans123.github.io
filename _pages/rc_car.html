This project is a personal smart RC car build powered by a Raspberry Pi, an L298N motor driver, and an external 9V power supply. I designed it to drive the motors electronically while using an HC-SR04 ultrasonic sensor for object detection and an override protocol to prevent collisions.

The main idea was to combine basic robotic mobility with a simple safety layer. Instead of allowing direct motor movement all the time, the car checks the distance to nearby objects and can override a user movement command when an obstacle is too close.

What It Does

  • Uses a Raspberry Pi as the main controller.
  • Drives the DC motors through an L298N motor driver.
  • Uses an external 9V supply for motor power.
  • Measures front distance using an HC-SR04 ultrasonic sensor.
  • Overrides forward movement when a collision risk is detected.

Hardware Used

  • Raspberry Pi
  • L298N motor driver
  • DC motors and RC car chassis
  • HC-SR04 ultrasonic sensor
  • External 9V power supply
  • Jumper wires and support electronics

How I Built It

The Raspberry Pi sends direction signals to the L298N motor driver, which controls the left and right drive motors. The HC-SR04 continuously measures the distance in front of the car and feeds that information back to the control logic.

I added an override protocol so the car does not blindly follow motion commands. When the sensor detects that an object is too close, the software can stop or block the movement command to prevent the car from colliding with obstacles.

Key Takeaways

  • Hands-on experience with Raspberry Pi motor control and robotics wiring.
  • Practical use of an ultrasonic sensor for distance-based safety decisions.
  • Understanding of how hardware override logic improves robotic reliability.
  • A strong base for adding autonomous navigation features later.
