Plant GPT is a personal Raspberry Pi project I built to monitor soil moisture and help users know when a plant needs watering. It uses a moisture sensor placed in the soil, reads the sensor values through a Raspberry Pi, and responds with alerts or recommendations when the soil becomes too dry.

The goal of the project was to build a simple smart-plant assistant that combines sensing, automation, and user-facing feedback. It gave me practical experience in sensor calibration, hardware-software integration, and turning raw sensor data into useful messages for day-to-day use.

What It Does

  • Measures moisture level in the soil using a moisture sensor.
  • Checks whether the plant has enough water.
  • Sends alerts or responses asking the user to water the plant when the soil is dry.
  • Helps reduce guesswork in plant care with direct sensor-based feedback.

Hardware Used

  • Raspberry Pi
  • Soil moisture sensor
  • Power supply and jumper wiring
  • Plant pot / soil test setup

How I Built It

The Raspberry Pi reads moisture values from the soil sensor and compares them against a threshold to decide whether the plant is sufficiently watered. When the value drops below the desired moisture level, the system generates a message or alert asking the user to water the plant.

I focused on making the output understandable instead of showing only raw numbers, which makes the project feel more like a helpful plant assistant. The setup can be extended later with logging, scheduled checks, web notifications, or support for multiple plants.

Key Takeaways

  • Experience working with Raspberry Pi sensor input for real-world monitoring.
  • Practical understanding of moisture sensing and threshold-based decision logic.
  • Improved skills in designing user-friendly hardware alerts.
  • A useful foundation for more advanced smart-garden automation projects.
